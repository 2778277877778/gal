# 《高中校园物语》变量命名规范 v1.0

> 唯一口径。代码侧以 `game/systems/stats.rpy` 为准，策划侧以 `回合事件表_v3.md` 为准，本表把两边钉在一起。
> 改任何 key（改名 / 新增 / 删除），三处必须同一次改完：本表 + `stats.rpy` + 回合事件表 §3 §5。

## 命名规则

1. 代码里的 key 一律**英文小写 snake_case**；中文只出现在 label 文字、台词、注释里，不进 key。
2. 同一个字符串**不许既当行动 key 又当 Flag 名**（旧 `club` 就是这种情况，这次拆开）。
3. 行动 key 用**动词开头**（`attend_` / `study_` / `listen_` / `visit_`），Flag 用**事件或状态名词**（`art_fair` / `piano_crisis` / `found_piano_room`）。
4. key 里不塞角色真名；`ask_zhoumo` 是唯一保留的角色名 key（周墨是固定女主，不是现实人物代称）。
5. 数值只改 `stats.rpy`，剧情里不写 `$ study += 5`。

## 1. 数值（store 变量）

| key | 中文 | 初始值 |
|---|---|---|
| `study` | 学习 | 30 |
| `stress` | 压力 | 10 |
| `stamina` | 体力 | 40 |

| `ap` | 行动点 | 3（T8 为 2） |

## 2. 常量（`stats.rpy` 里只写一处）

`STAT_INIT`、`ALLOWANCE_PER_MONTH`=150、`AP_PER_MONTH`=3、`AP_LAST_MONTH`=2、`STRESS_INSOMNIA`=80、`STRESS_SICK`=95、`STAMINA_LOW`=20、`EXAM_LINES`、`END_STUDY`=75、`END_STRESS`=70、`TRUE_FLAGS`。

初始值只从 `STAT_INIT` 取，`default` 行不再重复写数字。

## 3. 考试线 key（英文）

| 旧 key | 新 key | 及格线 |
|---|---|---|
| `"月考"` | `"monthly"` | 35 |
| `"期中"` | `"midterm"` | 50 |
| `"期末"` | `"final"` | 60 |
| `"学年期末"` | `"yearly"` | 70 |

接口定稿：`exam_roll()` 不接参数（得分 = 学习 + 随机 ±5）；`exam_pass("midterm")` 接上表 key 查及格线。掷点只掷一次，结果存 `store.exam_score`（`default exam_score = 0`），`exam_pass` 只拿它跟及格线比，别在 `exam_pass` 里再掷——否则同一回合查两条线会是两个不相干的随机数。

### 回合内选择变量

不是 Flag、但要跨回合读的选择，用 `t<回合号>_<含义>` 命名，值是小写英文短词，在 story 文件顶部 `default` 声明一次：

```renpy
default t1_answer = ""      # deny / ask / fumble
default t1_candy  = ""      # hand / step / via_zzb
default t1_night  = ""      # look / listen
```

T1 已经按这个写法落地（`game/story/t1_september.rpy`）。别用 `choice1`、`flag_a` 这种编号名，也别把这类变量塞进 `flags` 字典——`flags` 只放 13 个正式 Flag。
