# 高中校园物语

一个男生在高一这一年，帮一个把花藏在楼顶的女孩，把花养到太阳底下。Ren'Py 做的校园视觉小说，简体中文，13+，先出 Windows 版。

Demo 是高一学年，9–12 月和次年 3–6 月，一个月一回合，共 8 回合，读完大概 20 到 60 分钟。只做周墨这一条线，两个结局。完整版想做到高三。

玩法借了《火山的女儿》的日程和属性，地图是《星露谷》那种点着走的。

## 现在能玩到哪

从主菜单进去，能一路打到十一月。九月是全稿，十月、十一月只有骨架，台词还是 `〔待补〕`。事件表已经排到次年六月，剧本没跟上。

数值和存档是通的：学习、压力、体力、金钱四项，每月 3 点行动点，考试按线判，压力太高会失眠、体力太低学习减半。界面是 1920×1080 的全中文界面，标题、对白条、选项按钮都是自己画的。

缺的是十月和十一月的台词，十二月到六月的剧本，还有地图、个人界面、立绘、背景和音乐。背景现在全是纯色块，素材目录基本空着。

## 怎么跑

装 Ren'Py 8.5.3 SDK，解压就行，不用装进系统。仓库里带了 `dev.cmd`，会自己找 SDK：

```
dev.cmd            默认跑 lint
dev.cmd run        开游戏
dev.cmd test       冒烟用例
dev.cmd compile    生成 .rpyc
dev.cmd distribute 打包
```

找不到 SDK 就设 `RENPY_SDK` 环境变量，或者把它放到仓库旁边的 `tools\` 里。其余细节见 [依赖.md](依赖.md)。

提交前把 lint 和 test 跑一遍。改过界面、Flag 名或者节点表之后尤其容易出问题。

## 几个约定

数值别在剧情里直接改，走 `stats.rpy` 的函数。剧本先用 markdown 写，标好 bg、bgm、选项和 Flag，再转 `.rpy`。

key 一律小写 snake_case。改一个 key 要同时改三处：规范表、`stats.rpy`、回合事件表。回合内的临时选择写成 `t<回合号>_<含义>`，在 story 文件顶部 `default` 一次，不要塞进 `flags`——`flags` 只放那 13 个正式 Flag。

玩家能输入的字符串，插值一律用 `[name!q]`，不要用 `[name]`。

主角名先占位 `XXX`，那个班级活动的角色也还没定名，暂时叫 GAY。定了之后全仓替换一次。
